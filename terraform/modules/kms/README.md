# AWS KMS Terraform Module

## Purpose

Creates a customer-managed AWS KMS key for encrypting enterprise cloud resources.

## Features

- Customer Managed KMS Key
- Automatic Key Rotation
- Configurable Deletion Window
- KMS Alias
- Enterprise Tagging

## Resources

- aws_kms_key
- aws_kms_alias

## Outputs

- KMS Key ID
- KMS Key ARN
- KMS Alias
